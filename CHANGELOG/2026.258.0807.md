# 2026.258.0807 — feat(settings): expose vm.image_dir (set/get/list/reset)

## Summary of changes

Wire the new `vm.image_dir` runtime setting (spec#135) through every settings surface so
operators can point the VM disk-image root anywhere (default `image`, env
`CHARLY_VM_IMAGE_DIR`):

- `get` — `GetConfigValue` returns the resolved value (`config.go`);
- `set` — `SetConfigValue` validates (rejects an empty value) and persists;
- `reset` — `ResetConfigValue` clears it back to the default;
- `list` — `ListConfigValues` gains `resolve("vm.image_dir", "CHARLY_VM_IMAGE_DIR", cfg.Vm.ImageDir, "image")`;
- the unknown-key help text in all three error paths.

Also bumps the pins to the MERGED contract tags: **`sdk v0.2026234.347 → v0.2026258.154`**
(carries `VmDiskRoot`/`VmDiskDir`) and **`spec v0.2026232.520 → v0.2026257.1817`** (the
`vm.image_dir` field) — no local replace. This PR thus both advances the pins AND consumes
them; `kit.LoadRuntimeConfig` resolves `cfg.Vm.ImageDir` at THIS pin.
